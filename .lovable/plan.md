
## Что делаем

Добавляем печать в двух местах:

1. **Записи по дням** (`/schedule`) — на каждой карточке записи кнопка «Печать» → открывает окно печати с заказ-нарядом.
2. **Калькулятор** (`/calculator`) — кнопка «Печать» рядом с итогом → печать текущего набора выбранных работ.

## Заказ-наряд (для записи)

Печатная форма A4, шапка «Автосервис Самсон», номер записи (короткий id), дата/время, мастер. Блоки:

- **Клиент**: ФИО, телефон.
- **Автомобиль**: марка, модель, год, кузов, двигатель, госномер, VIN (если есть).
- **Работы**: таблица — № / наименование / цена. Итог снизу.
- **Оплата**: статус, внесено, к доплате.
- Подписи: «Клиент ____» / «Мастер ____».

## Печать из калькулятора

Шапка «Предварительный расчёт», дата, выбранный автомобиль (марка/модель/год, если выбран). Таблица работ с ценами и итогом. Без блока клиента/оплаты.

## Реализация

- Новый компонент `src/components/PrintOrder.tsx` — рендерит скрытый по умолчанию блок с классами `print:block hidden`, стили печати через Tailwind `print:` + небольшой `@media print` в `styles.css` (скрыть `.no-print`, задать A4, шрифт).
- Печать через `window.print()`. Чтобы не печатать всю страницу, использую подход «print-only контейнер»: на время печати рендерим отдельный портал с содержимым заказ-наряда, остальному контенту ставим `print:hidden`.
- В `/schedule` — иконка принтера на карточке; клик → готовит данные из уже загруженной записи → `window.print()`.
- В `/calculator` — кнопка «Печать» рядом с «Очистить/Итого» → печатает текущий список.

## Файлы
