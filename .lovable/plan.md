## Что меняем во вкладке «Мастера»

### 1. Блок «Зарплата» — две суммы вместо одной
Сейчас показывается только «Заработано (мастеру)». Сделаем два блока рядом за выбранный период:
- **Оборот по услугам** — общая сумма услуг, в которых участвовал мастер (цена клиенту).
- **Зарплата мастера** — сумма его выплат по этим услугам + средний процент (например, «14 500 ₽ · 50% от оборота»).

Плитку «Ожидает» оставляем — она полезна.

### 2. Провалиться в услугу — увидеть клиента и машину
Расширим API `listMechanicPayouts`, чтобы возвращались клиент, марка/модель/госномер. В списке услуг под цифрами каждая строка становится кликабельной: раскрывается панель с деталями (клиент, машина, дата/время, комментарий записи, сумма клиенту, сумма мастеру). Плюс переход в саму запись.

### 3. Ставка 50% по умолчанию
- Миграция: у `services.default_payout_percent` дефолт уже 50 — оставляем; добавляем колонку `mechanics.default_payout_percent NUMERIC NOT NULL DEFAULT 50`.
- В диалоге записи (`AppointmentDialog`) при расчёте выплаты приоритет такой: индивидуальная ставка мастера за конкретную услугу (`mechanic_service_rates`) → процент от `mechanics.default_payout_percent` → процент от `services.default_payout_percent` → 50%.
- В карточке мастера добавляем поле «Процент по умолчанию» (число + %), сохраняется по blur.

### 4. Авансы прямо в карточке мастера
Под блоком «Зарплата» добавляем блок **«Авансы»** за тот же период (Сегодня / Неделя / Месяц / Всё время):
- Плитка «Выдано авансов: X ₽» и «К выплате: Заработано − Авансы».
- Список авансов с датой и примечанием, кнопка «Удалить».
- Кнопка «+ Аванс» — форма (дата, сумма, примечание). Пустой список рисуем явно: «Авансов нет».
