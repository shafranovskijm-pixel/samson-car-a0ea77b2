
## Что делаем

Сделать все 4 карточки на странице `/expenses` (Чистая прибыль, Доходы, Зарплаты, Прочие расходы) кликабельными. По клику открывается модалка с детальной расшифровкой за выбранный период (день / неделя / месяц) — откуда взялась каждая цифра, построчно.

## Поведение карточек

Курсор pointer + hover-подсветка. Клик → `Dialog` (на мобильных — полноэкранный, как в AppointmentDialog). В шапке диалога: название метрики, период (например «Июль 2026» / «Неделя 27 июл – 2 авг» / «28 июл 2026»), итоговая сумма крупно.

### 1. Чистая прибыль
Формула сверху:
```
Чистая прибыль = Касса − Начисленная ЗП мастеров − Прочие расходы
6 009 ₽       = 14 650 ₽ − 5 071 ₽ − 3 570 ₽
```
Три строки-ссылки на остальные три диалога (переоткрывают соответствующий диалог).

### 2. Доходы (Касса)
- Итог: сумма всех `appointment_payments.amount` за период (после чистки осиротевших/переплат — уже в API).
- Таблица: дата платежа · клиент · машина · услуги записи (список) · метод · сумма.
- Секция «Ожидается» отдельным блоком: список записей со статусом `partial`/`unpaid` в периоде — цена, оплачено, остаток.

### 3. Зарплаты (мастера)
- Итог «Начислено»: сумма `effectivePayout` по всем услугам завершённых записей периода.
- Группировка по мастеру → раскрывающийся список услуг: дата · авто · услуга · цена · % · ЗП.
- Внизу по каждому мастеру: Начислено − Авансы за период = К выплате.
- Пояснение формулы % (индивид. мастера → % услуги → 50%).

### 4. Прочие расходы
- Список всех записей `expenses` за период: дата · название · заметка · сумма · кнопка удалить (та же логика, что в текущем списке).
- Итог снизу.

## Технически

- Один новый компонент `src/components/ExpensesDrillDown.tsx` с `type Metric = "profit" | "income" | "payout" | "expense"` и props `{ metric, open, onOpenChange, period, rangeStart, rangeEnd, appts, advances, expenses, mechanics, mechById, svcById }`. Внутри `switch(metric)` рендерит соответствующую секцию. Данные не дозагружает — берёт уже загруженные `useQuery`-данные из `expenses.tsx` (передаются пропами).
- В `src/routes/expenses.tsx`: карточкам в `ExpensesBlock` добавить `onClick` + состояние `const [drill, setDrill] = useState<Metric | null>(null)`. Никакой рефакторинг существующих блоков не требуется.
- Форматирование сумм — существующий `fmt`. Даты — `date-fns` + `ru`.
- Внутренние переходы между диалогами (из «Чистой прибыли») через смену `drill` state.
