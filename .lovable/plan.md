1. Исправить найденную причину ошибки в калькуляторе
- Ошибка из скриншота: `there is no unique or exclusion constraint matching the ON CONFLICT specification`.
- В коде добавление услуги для конкретной машины делает сохранение с конфликтом по полям `brand_name, model_name, year, category, name`, но в базе для `car_custom_services` сейчас есть только первичный ключ `id`; уникального правила для этой связки нет.
- Добавлю в базу уникальное правило для связки: марка + модель + год + категория + название услуги.
- После этого повторное сохранение одинаковой услуги для той же машины будет не дублировать строку, а обновлять цену и длительность.

2. Улучшить обработку ошибки в интерфейсе
