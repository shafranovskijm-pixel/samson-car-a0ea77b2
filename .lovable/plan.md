
## Что делаем

В разделе **Расходы** добавляем новую вкладку **«Сводная таблица»** (рядом со «Сводка / По мастерам / По услугам»). Это одна общая таблица за выбранный месяц — как рукописный журнал на фото — с кнопками **«Печать»** и **«Скачать Excel»**.

## Колонки таблицы

| Число | Марка / машина | Гос. номер | Работа | Мастер | % | Сумма работы | ЗП мастера | Аванс |
|---|---|---|---|---|---|---|---|---|

- **Число** — дата записи (`appointments.starts_at`, формат `дд.мм`).
- **Марка / машина** — `brand.name + model` (+ год при наличии).
- **Гос. номер** — `cars.license_plate`.
- **Работа** — название услуги из `appointment_services`.
- **Мастер** — `mechanics.full_name` из записи.
- **%** — эффективная ставка (мастер → услуга → 50%).
- **Сумма работы** — `appointment_services.price`.
- **ЗП мастера** — рассчитывается через `effectivePayout` из `src/lib/payouts.ts`.
- **Аванс** — сумма аванса именно этой строки (см. ниже).

Одна строка = одна услуга в записи (если в записи 3 услуги — 3 строки). Внизу — итоговая строка: суммы работ, ЗП, авансов.

## Как считаем аванс «этой строки»

Авансы (`mechanic_advances`) не привязаны к конкретной услуге, поэтому «аванс строки» = аванс мастера, выплаченный в **день** этой работы. Если у мастера в этот день несколько работ — аванс показываем только в первой строке этого мастера за этот день, чтобы не задваивать сумму. Итог по колонке всё равно совпадёт с общей суммой авансов за месяц.

## Фильтры / управление

- Селектор месяца — использует существующий `monthStart/monthEnd` из `expenses.tsx`.
- Фильтр «Мастер» (все / конкретный) — по умолчанию все.
- Только `appointments.status = 'done'` (как в остальной бухгалтерии).

## Печать

Кнопка **«Печать»** — открывает системный диалог через `window.print()` с CSS-режимом `@media print`, скрывающим сайдбар/шапку и показывающим только таблицу + заголовок «Сводная за <месяц>». Используем существующий подход из `src/components/PrintDocument.tsx`.

## Экспорт в Excel

Кнопка **«Скачать Excel»** — генерируем `.xlsx` на клиенте через библиотеку **`xlsx`** (SheetJS, ~200 КБ, работает офлайн — важно для Electron-сборки). Файл: `Свод_<Месяц>_<Год>.xlsx`. Ставим ширину колонок и жирный заголовок.
