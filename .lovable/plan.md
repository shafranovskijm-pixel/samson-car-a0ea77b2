### 2. Поиск клиентов по номеру машины и комментариям
В `src/routes/clients.tsx`:

### 3. Кнопка «Добавить услуги» в карточке клиента → калькулятор
В `src/routes/clients.tsx` (детали клиента):
- Кнопка «Добавить услуги» рядом со списком машин или на каждой машине клиента.
- Переход на `/calculator?carId=<uuid>` (или `clientId=...&carId=...`).

В `src/routes/calculator.tsx`:
- Читать `carId`/`clientId` из URL (search params).
- Если передан `carId` — найти машину клиента, автоматически подставить марку/модель/год (из `cars` + `car_models` + `brands`), пропустить шаги выбора и сразу открыть экран выбора услуг.
- Если данных о модификации нет — открыть шаг «Модификация» с уже выбранными марка/модель/год.

### 4. Исправить расчёт в «Расходах»
В `src/routes/expenses.tsx` изменить формулы:
- **Оборот за месяц** = сумма `paid_amount` по записям (реально полученные деньги), а не `total_price` всех «done».
- **ЗП мастеров (начислено)** — оставить как справочную цифру (по выполненным работам за месяц).
- **ЗП мастеров (выплачено)** = сумма `mechanic_advances` за месяц — именно она вычитается из прибыли как расход.
- **Прочие расходы** = как сейчас.
- **Чистая прибыль** = Оборот (оплачено) − ЗП выплачено (авансы) − Прочие расходы.
- Показать 5 плиток вместо 4: Оборот (оплачено), Начислено мастерам, Выплачено мастерам, Прочие расходы, Чистая прибыль.
- В разделе «По мастерам» отдельно показывать «Начислено / Выплачено / Остаток к выплате» (в основном уже есть — сверить формулу).
