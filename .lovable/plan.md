## Что сделаю

1. **Сборка Windows-приложения**
   - Запущу `npm run build:electron` (SPA-сборка в `dist-electron-web/`).
   - Запущу `electron-packager` с `--platform=win32 --arch=x64` → получится папка `SamsonCRM-win32-x64/` с `SamsonCRM.exe` внутри и всеми нужными DLL/ресурсами.
   - Упакую всю папку в один zip-архив `SamsonCRM-windows.zip` (пользователь распакует и запустит `SamsonCRM.exe` — двойным кликом, без установки).
   - Примечание: настоящий инсталлятор `.exe` (типа Setup.exe) требует `electron-builder`, который в песочнице Lovable не работает из-за отсутствия нужных бинарников. Поэтому будет **портативная сборка в zip** — это стандартный и рабочий вариант для Electron.

2. **Публикация файла для скачивания**
   - Залью `SamsonCRM-windows.zip` через `lovable-assets` — он окажется на CDN Lovable и будет доступен по стабильному URL как из preview, так и с опубликованного сайта (`samson-car.lovable.app`).
   - Сохраню pointer `public/downloads/SamsonCRM-windows.zip.asset.json` (или в `src/assets/`), чтобы ссылка жила в проекте.

3. **Кнопка «Скачать для Windows» на странице логина**
   - В `src/routes/login.tsx` под формой добавлю блок со ссылкой на скачивание zip-архива и коротким пояснением: «Оффлайн-версия для Windows. Логин и пароль те же: admin555 / admin555».
   - Ссылка — обычный `<a href={asset.url} download>`.

4. **Что внутри exe уже работает (не меняю)**
   - Тот же интерфейс CRM, тот же вход `admin555 / admin555` (данные логина хранятся в `localStorage` внутри Electron).
   - Оффлайн-кэш TanStack Query уже настроен (`src/lib/offlineCache.ts`), синхронизация с облаком идёт при появлении интернета.

## Ограничения, о которых честно предупреждаю

- Сборка получится **под Windows x64** (подходит для всех современных Windows 10/11 64-bit).
- Это **портативный zip**, а не установщик. Пользователь скачивает → распаковывает → запускает `SamsonCRM.exe`. Ярлык на рабочий стол при желании создаётся вручную.
- Windows SmartScreen при первом запуске может показать предупреждение (сборка без подписи кодом) — это нормально для внутренних приложений, нажать «Подробнее → Выполнить в любом случае».
- Размер архива ~90–120 МБ (Electron сам по себе весит столько).
