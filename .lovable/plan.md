## Как это будет выглядеть

### Селектор услуг (главное поле «Добавить услугу»)
```
[ 🔍 Поиск услуги…                    ▼ ]  [ + ]
   ├─ Жидкости и фильтры
   │    Замена масла ДВС           1500 ₽
   │    Замена масла АКПП          4550 ₽
   ├─ Тормоза
   │    Замена колодок передних    2000 ₽
```
- Поле ввода фильтрует по подстроке (без учёта регистра) по названию и категории.
- Уже добавленные в запись услуги скрыты.
- Клик по строке = сразу добавляет услугу в запись (кнопка «+» остаётся для клавиатуры).
- Пустой результат → строка «Ничего не найдено — добавьте свою услугу ниже» со скроллом к форме кастомной услуги.

### «Добавить свою услугу» с проверкой дублей
При нажатии «Добавить»:
1. Нормализуем строку (`trim`, привести пробелы к одинарным, `toLowerCase` для сравнения).
2. Ищем совпадение среди `services` (по паре `category+name`, точное) и «похожие» (одна из строк содержит другую).
3. Если нашли **точное совпадение** — не создаём новую, а:
   - показываем карточку найденной услуги с её текущей ценой,
   - две кнопки: **«Добавить в запись»** (использовать текущую цену) и **«Обновить цену и добавить»** (перезаписать `service_prices` введённой ценой),
   - тост: «Такая услуга уже есть».
4. Если нашли **похожие** (не точное) — показываем список кандидатов (до 5) над кнопкой «Добавить», с подписью «Похоже, есть уже такие:». Каждый — кнопка «Выбрать». Пользователь либо выбирает существующую, либо всё равно жмёт «Добавить», и тогда создаём новую.
5. Если совпадений нет — обычное создание через `upsertServiceByCategoryName` + `carCustom.add`.

Требование «выберите машину с указанным годом» распространяем только на шаг сохранения в справочник машины (`carCustom.add`); поиск дублей и добавление в запись работают всегда.

### Ошибки
- В `addCustomService`, `pickSavedCustom`, `addService` обернуть `catch` так, чтобы:
  - `console.error("addCustomService failed", e)` — полный объект в консоль,
  - `toast.error(mapError(e))` — короткое сообщение (маппинг ключевых кодов Postgres/Supabase: `23505` → «Такая услуга уже есть», `PGRST301`/`401` → «Нет доступа», сетевые → «Нет соединения», иначе `e.message` или «Не удалось сохранить услугу»).
- Тот же `mapError` использовать в остальных мутациях диалога, чтобы сообщения были единообразными.

## Проверка после сборки

1. Открыть запись → в «Добавить услугу» ввести часть названия — список фильтруется, клик добавляет услугу.
2. В «Добавить свою услугу» ввести существующее название → появляется карточка «Такая услуга уже есть» с двумя кнопками; дубль в БД не создаётся.
3. Ввести название, похожее на существующее (например «замена масло») → показываются кандидаты; можно выбрать.
4. Ввести уникальное название с выбранной машиной+годом → создаётся и запоминается для машины.
5. Спровоцировать ошибку (например, отключить сеть) → тост короткий и понятный, полный стек — в консоли браузера.
