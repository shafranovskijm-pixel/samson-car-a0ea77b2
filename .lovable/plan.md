## 1. Ставки мастера за услуги (редактируемые)

**Новая таблица `mechanic_service_rates`:**
- `mechanic_id` → mechanics
- `service_id` → services
- `amount` (numeric) — сколько получает мастер за эту услугу
- UNIQUE(mechanic_id, service_id)

Ставка редактируется в карточке мастера (см. п.3). Если ставки для услуги нет — по умолчанию 0 (можно вводить вручную при записи).

## 2. Начисления мастеру при записи

**Изменения в `appointment_services`:**
- Добавляем колонку `mechanic_payout numeric NOT NULL DEFAULT 0` — сколько уходит мастеру за эту услугу в этой конкретной записи.

**В диалоге записи (`AppointmentDialog.tsx`):**
- Когда выбран мастер и добавляется услуга, автоматически подставляется ставка из `mechanic_service_rates` (или 0, если не задана).
- Рядом с ценой услуги для клиента показываем поле «Мастеру, ₽» — можно перебить руками для конкретной записи.

Начисление считается «заработанным» только когда статус записи = `done`.

## 3. Карточка мастера (`/mechanics` → детальная страница/диалог)

Переделываем страницу «Мастера» из плоской таблицы в двухпанельный вид (список слева, детали справа — как в клиентах):

**В деталях мастера:**
- **Ставки за услуги** — таблица «Услуга / Ставка (₽)», редактируемая, сохраняется в `mechanic_service_rates`.
- **Зарплата (заработано)** — сумма `mechanic_payout` по всем `appointment_services` из записей мастера со статусом `done`. Фильтр периода: сегодня / неделя / месяц / всё время. Показываем итог и список записей с суммой.
- **График смен** — см. п.4.
- Поля ФИО/специализация/телефон/цвет — как сейчас.

## 4. График смен мастера

**Новая таблица `mechanic_shifts`:**
- `mechanic_id` → mechanics
- `starts_at`, `ends_at` (timestamptz)
- `note` (text, необязательно)

**UI:** в карточке мастера — блок «График смен» со списком ближайших/прошедших смен, кнопка «+ Смена» (дата + время начала/конца + заметка).

В календаре смены пока не отображаем — только список в карточке мастера (если понадобится в календаре как «фон» — сделаем отдельно, чтобы не раздувать этот шаг).

## 5. Часы Уссурийска в глобальном хедере

Сейчас живые часы (Asia/Vladivostok) показываются только на странице «Календарь». Переносим их в общий хедер `src/routes/__root.tsx` (рядом с «Samson Auto — CRM») — будут видны на всех страницах. Из `calendar.tsx` виджет убираем (логика проверки прошедших слотов остаётся).

## Технические детали

- Миграции: `mechanic_service_rates`, `mechanic_shifts`, `ALTER appointment_services ADD mechanic_payout`. RLS: authenticated CRUD, стандартные GRANT.
- API-функции в `src/lib/api.ts`: list/upsert/delete rates; list/create/update/delete shifts; list `appointment_services` по мастеру за период для расчёта ЗП.
- Тип `AppointmentWithRelations.services` расширяется полем `mechanic_payout`. `createAppointment`/`updateAppointment` пробрасывают payout.
- Общий хедер: маленький компонент `<UssuriyskClock />`, использует `Intl.DateTimeFormat` с `timeZone: "Asia/Vladivostok"`, обновляется каждую секунду.
