## Что делаем

На карточке клиента (в шапке, рядом с «Изменить»/«В архив») добавляем кнопку **«+ Добавить услугу»**. По нажатию:

- Если у клиента **0 машин** — тост «Сначала добавьте машину» + автооткрытие диалога добавления машины.
- Если **1 машина** — сразу переход в `/calculator?carId=<id>` (калькулятор уже сам префиллит авто и переключается на шаг «Услуги»).
- Если **≥2 машин** — открывается компактный диалог со списком машин клиента (марка + модель + год + госномер). Клик по машине → переход в калькулятор на шаг «Услуги» с этой машиной.

Существующие кнопки-иконки калькулятора и «Добавить услуги» внутри карточек машин **оставляем как есть** — они удобны, когда пользователь уже смотрит на конкретную машину.

## Технические детали

- Файл: `src/routes/clients.tsx`.
- Секция шапки клиента (где сейчас категория, «Изменить», «В архив», «Удалить») — добавить `Button` с иконкой `CalculatorIcon` и текстом «Добавить услугу». На мобилке — только иконка, на desktop — иконка + текст, чтобы не ломать текущий ряд.
- Локальный `useState` `pickCarOpen: boolean`. Логика клика:
  - `selectedCars.length === 0` → `toast.info(...)` + `setCarDialog({ open: true, editing: null, clientId: selected.id })`.
  - `=== 1` → `navigate({ to: "/calculator", search: { carId: selectedCars[0].id } })`.
  - `> 1` → `setPickCarOpen(true)`.
- Диалог выбора: `Dialog` из shadcn, список кнопок-строк по `selectedCars`. Каждая строка: `{brand} {model}`, ниже — `{year} · {license_plate ?? "—"}`. `onClick` — тот же `navigate`, затем закрыть диалог.
- Навигация: `useNavigate()` из `@tanstack/react-router` (уже используется в проекте).
- Никаких изменений в `src/routes/calculator.tsx` не нужно — префилл по `carId` и переключение на шаг «Услуги» уже работают (`useEffect` на строках 281–298).

## Что не трогаем

- Логика калькулятора, БД, ЗП, платежей.
- Существующая карточка машины и её кнопки.
