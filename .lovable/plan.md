## Что улучшаем

Сейчас в калькуляторе на главной выбирается только марка авто → применяется коэффициент класса марки. Проблема: внутри одной марки модели сильно отличаются (Toyota Corolla ≠ Toyota Land Cruiser), поэтому одинаковый коэффициент даёт неточную цену. Добавим выбор модели и привяжем коэффициент к модели, а не к марке.

## Что делаем

1. **Справочник моделей** — новая таблица `car_models` (brand_id, name, tier). Тир по умолчанию наследуется от марки, но у модели может быть свой (Camry — комфорт, Land Cruiser — премиум).
2. **Сидинг моделей** — засеять ~15–40 популярных моделей на каждую из ~60 марок (итого ~1500 записей) миграцией. Данные подготовлю из открытых источников (Wikipedia lists, каталоги). Если каких-то марок/моделей будет не хватать — можно будет добавить вручную в разделе «Марки» или ты пришлёшь список от ChatGPT.
3. **Калькулятор на главной**:
   - После выбора марки появляется второй селект «Модель» (с поиском, как у марки).
   - Коэффициент берётся из модели; если у модели нет своего tier — из марки.
   - В итоговой панели показываем «Toyota Camry · Комфорт (×1.3)».
4. **Форма машины клиента** (`/crm/cars`) — заменим текстовое поле `model` на селект из `car_models` для выбранной марки, с fallback «Другая…» → свободный ввод (сохраним старое поведение для редких моделей).
5. **Раздел «Марки»** — добавим вложенный список моделей у каждой марки: добавить / переименовать / удалить / сменить tier. Чтобы можно было донастроить справочник без миграций.

## Технические детали

- Миграция: `car_models(id uuid pk, brand_id uuid fk, name text, tier text null)`, unique(brand_id, name), GRANT + RLS как у остальных таблиц.
- API в `src/lib/api.ts`: `listModels(brand_id?)`, `createModel`, `updateModel`, `deleteModel`.
- Типы: `CarModel` в `types.ts`; helper `resolveTier(brand, model)` → tier для расчёта.
- Данные сидинга готовлю сам (плоский SQL insert по каждой марке). Если после сидинга каких-то моделей не хватит — добавишь через UI или пришлёшь дополнительный список.
- `car.model_id` (nullable) добавим к таблице `cars` рядом с текущим `model` (текст оставим для обратной совместимости и «Другая…»).

## Открытый вопрос

Готов сам собрать список моделей (~1500 строк) — это займёт одну итерацию. Если хочешь более полный/выверенный список — пришли выгрузку от ChatGPT в формате `Марка; Модель; класс(economy|comfort|business|premium|luxury)`, и я использую его вместо своего.
