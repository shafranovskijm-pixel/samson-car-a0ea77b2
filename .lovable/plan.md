## Что переделываем

Карточка одной записи в списке `/schedule` (файл `src/routes/schedule.tsx`, блок с `map((a) => …)`). Диалог «Новая запись» из скриншота не трогаем — там про адаптацию отдельно, если понадобится.

## Как сейчас (проблемы)

- На карточке видно только `HH:mm`, а дата — в заголовке дня выше. При скролле по длинному списку теряется контекст.
- На мобильных статусы/оплата/печать/удаление уезжают в кучу мелких «таблеток» справа, ломают ритм.
- Ряд `flex sm:flex-row` схлопывается неаккуратно: у длинных названий услуг и клиента нет `min-w-0`, у бейджей нет `shrink-0`, из-за чего строки прыгают.
- Нет визуального акцента статуса (Запланировано / В работе / Готово) — всё выглядит одинаково.

## Что делаем

1. **Левый «маркер времени»** — колонка с временем и датой.
   - Крупно: `HH:mm` (моноширинно, `tabular-nums`).
   - Мелко под ним: `21 июл` (день + короткий месяц), а для сегодняшних записей — бейдж «Сегодня», для завтрашних — «Завтра».
   - Цветовая полоска слева карточки в цвет статуса (`bg-<status>`), чтобы Запланировано / В работе / Готово / Отменено считывались сразу.
   - На десктопе колонка фиксированной ширины `w-20`, на мобильных — горизонтальная строка над контентом.

2. **Средняя зона** — машина, клиент, услуги.
   - `min-w-0` на всех вложенных блоках, `truncate` на одной строке, услуги — `line-clamp-1`.
   - Мастер переезжает сюда мелкой строкой с цветной точкой (сейчас он справа и дублирует место с ценой).

3. **Правая зона** — сумма и действия.
   - Сумма крупнее, под ней «внесено X ₽ из Y ₽» единой строкой (сейчас скобки в конце цены).
   - Кнопки «Статус», «Оплата», «Печать», «Удалить» перегруппированы:
     - На десктопе — в ряд справа, вертикально выровнены.
     - На мобильных — статус+оплата в одну строку (главные), печать/удалить в отдельную (иконочные, без подписи), чтобы не было переносов.
   - «Удалить» становится иконочной кнопкой в углу карточки (как обычно у карточек), чтобы не занимала место.

4. **Сетка карточки** — единый грид вместо flex-flex-row:
   ```text
   mobile:  [time+date] сверху, [контент] снизу, [действия] wrap-ом
   sm+:     grid-cols-[auto,minmax(0,1fr),auto]  ← время | контент | действия
   ```
   Отступы: `p-3 sm:p-4`, `gap-3 sm:gap-4`. Скругления `rounded-xl`, hover — лёгкое поднятие тени.

5. **Заголовок дня** остаётся, но с датой на карточке дубль не мешает — заголовок можно сделать `sticky top-0` полупрозрачным, чтобы при скролле было видно текущий день. (Мелкая приятность, не критично — если не хочешь, уберу.)

## Что не трогаем

- Логику мутаций (`setStatus`, `payFullNow`, `openPayDialog`, `clearPayMut`, `deleteMut`) и подтверждения.
- Диалог «Новая запись» и диалог платежа.
- Данные и типы.

## Файлы

- `src/routes/schedule.tsx` — только JSX карточки записи и стили; при необходимости пара мелких хелперов (`isToday`, `isTomorrow`) внутри файла.
