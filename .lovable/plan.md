## Что меняем

1. **Главная (/)** — новый дашборд со сводкой:
   - блок «Ближайшие записи» (сегодня + следующие 3 дня, из `appointments`),
   - счётчики: клиенты, машины, записи сегодня,
   - большие плитки-ярлыки: «Новая запись», «Калькулятор», «Клиенты», «Записи по дням».
   - Текущий яркий лендинг переносим в `/calculator` без потери дизайна.

2. **Калькулятор** переезжает внутрь CRM:
   - файл `src/routes/index.tsx` (лендинг с картинками) → `src/routes/calculator.tsx`,
   - работает внутри общего `SidebarProvider` (в шапке — крошки и триггер сайдбара),
   - в `__root.tsx` убираем ветку `isLanding` — теперь у всех страниц одна оболочка с сайдбаром.
   - В сайдбар добавляем пункт **«Калькулятор»** (иконка Calculator).

3. **Клиенты + Машины → один раздел «Клиенты»**:
   - страница `/clients` становится мастер-страницей: слева список клиентов, справа выбранный клиент с его машинами (несколько машин у одного клиента — уже поддерживается схемой, `cars.client_id`).
   - Карточка клиента: ФИО, телефон, email, кнопки «Изменить»/«Удалить», ниже блок «Автомобили» со списком его машин, кнопкой **«+ Добавить машину»** и inline-редактированием (тот же диалог, что был на `/cars`, но с предзаполненным клиентом).
   - Отдельная страница `/cars` удаляется (все её функции доступны из карточки клиента). Из сайдбара убираем «Машины».
   - На всякий случай `/cars` делаем редиректом на `/clients`, чтобы старые ссылки не ломались.

4. **Настройки калькулятора** — новый раздел `/settings` с двумя вкладками:
   - **Марки** — то, что было на `/brands` (марки + модели + класс).
   - **Услуги и цены** — то, что было на `/services` (услуги, категории, базовые цены и переопределения по маркам).
   - Старые пути `/brands` и `/services` перенаправляют на `/settings?tab=brands` и `/settings?tab=services`.

## Обновлённый сайдбар

```text
Разделы
├─ 🏠 Главная            /
├─ 📅 Календарь          /calendar
├─ 📋 Записи по дням     /schedule
├─ 🧮 Калькулятор        /calculator
├─ 👥 Клиенты            /clients        ← вместе с машинами
├─ 👤 Мастера            /mechanics
└─ ⚙️  Настройки калькулятора  /settings  ← марки + услуги
```

## Технические детали

- Новые файлы: `src/routes/index.tsx` (переписываем как дашборд), `src/routes/calculator.tsx` (перенос текущего лендинга), `src/routes/settings.tsx` (layout с вкладками через `Tabs`, состояние во URL `?tab=`).
- Удаляем `src/routes/cars.tsx`, `src/routes/brands.tsx`, `src/routes/services.tsx` — их содержимое переезжает.
- `src/routes/clients.tsx` переделываем в мастер-детейл: сохраняем `useQuery(["clients"])`, добавляем `useQuery(["cars-by-client", id])` и переиспользуем существующий диалог машины (вынесу в компонент `CarDialog`).
- `__root.tsx`: убираем `if (isLanding) return ...`, всегда рендерим `SidebarProvider` + `AppSidebar` + `Outlet`.
- `src/components/AppSidebar.tsx`: обновляем список пунктов.
- Никаких изменений в БД — схема уже поддерживает «клиент → много машин».
