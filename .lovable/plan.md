
## 1. Клиенты — архив

- Миграция: `clients.is_archived boolean not null default false`.
- В `Client` типе + в `listClients` (без фильтра, отдаём всех — фильтруем на клиенте).
- В левой колонке сверху — вкладки **Активные / Архив** (по умолчанию активные). Счётчик рядом с каждой.
- На карточке выбранного клиента, рядом с «Изменить»/«Удалить», кнопка **В архив** (или **Восстановить**, если уже в архиве). Мутация `updateClient({ is_archived })`.
- Архивные клиенты не попадают в селекты «Клиент» в диалоге записи (фильтруем на клиенте по `is_archived === false`).

## 2. Клиенты — поиск по хронологии

В компоненте `ClientHistory` (строки 713–776) добавляю поле поиска над списком. Фильтрует записи клиента по: названию услуги, марке/модели авто, госномеру, комментарию, статусу (`STATUS_LABELS`) и дате (форматированной строке `dd.mm.yyyy`). Пусто → показываем всё.

## 3. Мастера

### Больше цветов
Расширяю палитру `COLORS` в `src/routes/mechanics.tsx` с 8 до ~20 цветов (насыщенные и пастельные вариации), сетка выбора становится `grid-cols-10`.

### Окрашивание в цвет мастера
- В списке мастеров слева — левый цветной бордер (`border-l-4`) + мягкая подложка `background: color + '14'` (hex + alpha) на карточке; у выбранного — насыщеннее.
- В шапке правой панели у выбранного мастера — цветная полоса сверху карточки и цветной чип возле имени.
- В блоке «График смен» — карточки смен получают левый цветной бордер цветом мастера.

### «График работы»
Существующий блок «График смен» переименовываем в **«График работы»**. Улучшения:
- Группировка по неделям (заголовок «Неделя с 13 июля»).
- В каждой карточке смены — длительность (например «9 ч») справа.
- Прошедшие смены остаются приглушёнными.

Не трогаем схему `mechanic_shifts` — её достаточно.
